# System Admin Tool
A bash-based sysadmin toolkit with snapshot, audit, network, and disk space tools.

## Usage
```bash
bash menu.sh
```

## Tools
- **Snapshot** — captures system info to reports/
- **Audit** — logs users and sensitive files to reports/
- **Disk Checker** — checks disk usage with warnings
- **Network** — logs IP, DNS and connectivity to reports/
